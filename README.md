# Fior di Levante: Explore Zákynthos

A full-stack travel guide web application developed as part of the Web Programming course.

The application provides visitors with information about Zakynthos while allowing registered users to manage reservations, explore events and activities, and create personalized itineraries. An administrative interface is also available for managing platform content.

## Overview

"Fior di Levante" is a tourism-focused web application designed to help visitors discover and organize their trip to Zakynthos.

The project combines destination information, accommodation reservations, event bookings, activity discovery, and itinerary planning into a single platform.

## Features

## Modern Web Trends Implemented

### Responsive Web Design

The application was designed for:

- Desktop devices
- Tablets
- Smartphones

Responsive behavior was implemented using Bootstrap and custom CSS.

### Voice Search

Users can perform voice-based searches for activities, providing an alternative interaction mechanism alongside traditional search.

### Form Validation using AngularJS

AngularJS was used to validate registration and login forms before submission.
